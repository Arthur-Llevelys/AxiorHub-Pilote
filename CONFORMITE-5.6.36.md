# Conformité 5.6.36 — demandes de l’avocat du 12 octobre 2026

Version de référence : 5.6.35. Cette version traite les anomalies signalées (application Nextcloud, modèle de courrier, notifications,
page « Un instant… ») et ajoute les fonctions demandées (initiatives, données des pièces, outils IA, corporate, contacts, relances,
Microsoft).

Légende : **Réalisé** : livré et couvert par un test. **Partiel** : livré avec la limite indiquée. Sauf mention contraire, les tests
cités sont dans `tests/test_v5636.py` (66 tests). Toutes les données d’essai sont fictives.

## Correctifs

| Demande | État 5.6.36 |
|---|---|
| Application Nextcloud : on ne peut ni donner d’instruction, ni chercher, ni préparer une fiche | **Réalisé (application 0.3.0).** Onglets Pilote (instruction transmise au Pilote, réponse et sources affichées), Rechercher dans les dossiers, Fiche du dossier, Recherche juridique, Travaux récents. Contrat 1.2 : opérations `instruction` et recherche (`GET /integration/v1/search`). Tests moteur : `PersonalKeys` ; tests PHP (`tests/Unit/*`, 21 tests) ; essai de bout en bout PHP → moteur réussi (appairage, refus d’un mauvais mot de passe, dossiers, recherche, instruction, révocation). Limite : non installée sur un Nextcloud réel depuis le poste de construction. |
| Réglages Nextcloud réservés à l’administrateur alors que certains utilisateurs ne sont pas avocats | **Réalisé.** Chaque utilisateur relie son compte AxiorHub dans ses paramètres personnels Nextcloud ; le mot de passe est échangé contre une clé personnelle (jamais conservé), révocable dans AxiorHub (Paramètres › Connexions › Application Nextcloud). Un utilisateur non relié n’a aucun accès ; l’administrateur Nextcloud autorise seulement la liaison. 5 échecs d’appairage en 15 minutes bloquent l’adresse et l’identifiant. |
| « Le moteur AxiorHub est injoignable depuis ce serveur Nextcloud » | **Réalisé.** Causes trouvées : (1) un appel signé écrit un jeton à usage unique ; avec une base momentanément occupée, la page HTML « Un instant… » était renvoyée et lue comme « injoignable » ; (2) en mode Docker, `/integration/v1/` exigeait une session. Correctifs : réponse JSON 503 `moteur_occupe` réessayée automatiquement, délai d’écriture porté à 25 s, route d’intégration servie sans session (signature vérifiée), messages précis dans l’application. Tests : `IntegrationBusy`, `PersonalKeys`. |
| Modèle de courrier refusé (`modele-courrier-exemple.docx`) | **Réalisé.** Cause : la balise `{{envoi}}` était obligatoire ; seul `{{corps}}` l’est désormais. Les en-têtes, pieds de page et numéros de page n’étaient pas en cause. Le refus nomme la balise manquante ou inconnue. Le modèle fourni est accepté et s’affiche (1 page, LibreOffice). Tests : `LetterTemplate`. |
| README : promesse « jamais » sur les sources | **Réalisé.** Section « Sources et contrôles : ce qui est vérifié, ce qui reste à vous » (4 langues) : contrôles existants, limites, validation attendue de l’avocat. |
| Confidentialité : séparer le code des données du cabinet | **Réalisé.** Captures relues (données fictives) ; contrôle de confidentialité étendu aux métadonnées PNG et JPEG et aux journaux, bases et courriels hors des exemples ; signalement d’anomalie anonymisé (version, services, codes d’erreur seulement) ; modèles de ticket GitHub ; SECURITY.md complété. |
| Fenêtre du Pilote au milieu de l’écran, utilisable sur téléphone | **Réalisé.** Fenêtre centrée avec fond assombri (Échap ou clic pour fermer), icône inchangée à droite ; plein écran sur téléphone, icône masquée pendant l’ouverture. Vérifié dans le navigateur (bureau et 375 px). |
| Supprimer ou exclure une tâche de l’agent | **Réalisé.** « Écarter » sur une demande en erreur, « Annuler la mission » et « Retirer de la liste ». Tests : `Missions`, `Checks`. |
| Notification rouge d’« Aujourd’hui » inquiétante | **Réalisé.** Indicateur neutre en tête (« 2 points à vérifier ») ; détail « Points à vérifier — rien d’urgent » en bas de page, repliable, avec un bouton par point (relancer la surveillance, écarter les erreurs déjà vues, voir la file ou les dossiers). Un dossier illisible ne suspend plus la surveillance des autres ; une file pleine n’est plus une erreur. Tests : `Surveillance`, `Checks`. |
| Barre d’état et « Activité de l’assistant » repliables, repliées par défaut | **Réalisé.** Repliées sur toutes les pages (pastille en bas à droite), choix mémorisé dans le navigateur. Vérifié dans le navigateur. |
| Page « Un instant… » plus graphique et moins fréquente | **Réalisé.** Page graphique qui recharge la même adresse ; lectures réessayées automatiquement par l’interface ; délais d’attente adaptés (lecture 2 s, écriture 25 s) ; les écritures de plus de 5 s sont consignées avec leur origine dans le diagnostic. Tests : `Busy`. |
| Agents documentaires : sélection de dossiers, réglages simplifiés | **Réalisé.** « 📁 Ajouter un dossier… » ouvre l’arborescence Nextcloud (ou du dossier local) ; saisie manuelle repliée. Tests : `FolderPicker`. |
| Envoi direct | **Réalisé.** Paramètres › Messagerie : « Autoriser l’envoi quand je clique sur « Envoyer » », tous les dossiers ou ceux cochés, confirmation facultative. Tests : `DirectSend`. |
