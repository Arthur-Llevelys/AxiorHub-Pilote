# Politique de marque AxiorHub

La licence `AGPL-3.0-or-later` du fichier `LICENSE` couvre le code source. Elle
ne concède aucun droit sur la marque **AxiorHub** ni sur le nom de produit
**AxiorHub Pilote**, ses noms de produits, ses
signes distinctifs, ses noms de domaine ou leur habillage.

## Usages permis sans autorisation préalable

- mention nominative exacte pour indiquer la compatibilité ou l’origine, par
  exemple « dérivé du projet AxiorHub », sans suggérer une approbation ;
- redistribution d’une copie officielle, non modifiée, sous son nom d’origine ;
- captures d’écran et citations raisonnables à des fins de documentation,
  d’enseignement ou de commentaire.

## Usages soumis à autorisation

- présenter une version modifiée comme une version officielle d’AxiorHub ;
- utiliser AxiorHub dans le nom principal d’un produit, service, société ou nom
  de domaine tiers ;
- utiliser une identité visuelle susceptible de créer une confusion sur
  l’origine, l’édition ou le support du logiciel.

Les versions modifiées doivent clairement indiquer qu’elles ne sont pas une
édition officielle et utiliser leur propre identité de produit. Rien dans cette
politique ne limite les droits de copier, étudier, modifier et redistribuer le
code accordés par l’AGPL.

La licence du fichier logo est définie séparément dans `LOGO-LICENSE.md`.
